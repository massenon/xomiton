# Stratégie de contenu

## 1. Objectifs par page
| Page | Objectif principal | Objectif secondaire | Indicateur |
|---|---|---|---|
| Accueil | Créer un compte | Signaler sans compte / s'abonner à la newsletter | Taux de clic « Créer un compte » |
| Thématiques | Informer | Orienter vers l'aide | Temps de lecture, clics « J'ai besoin d'aide » |
| Ressources | Faire télécharger / lire | Créer un compte | Téléchargements |
| Violences, lois | Faire comprendre ses droits | Signaler | Clics « Signaler » |
| Do Glegbe | Informer sur l'hygiène menstruelle | Partager | Lectures, partages |
| Signaler | Recevoir un signalement exploitable | Code de suivi conservé | Taux de complétion du formulaire |
| SOS | Alerter vite | — | Délai déclenchement → accusé |
| Urgences | Appeler | — | Clics sur les numéros |
| Aide (FAQ) | Répondre sans contact | Créer un compte | Recherches sans résultat |
| Newsletter (pied de page) | Garder le lien | Faire revenir sur le site | Inscriptions confirmées, ouverture |

## 2. Parcours types
1. **Découverte** : recherche Google « droits LGBT Bénin » → thématique → lecture → « Créer un compte » ou newsletter.
2. **Urgence** : accueil ou lien partagé → SOS / urgences → appel.
3. **Témoignage** : accueil → « Je veux témoigner ou signaler un abus » → signalement anonyme → code de suivi → (plus tard) création de compte.
4. **Communauté** : invitation d'une amie → inscription → OTP → fil → premier commentaire → groupe → événement.
5. **Pair éducateur·rice** : inscription comme pair → validation → espace pair → collecte hors ligne → synchronisation.

## 3. Tunnel
```
Visiteur·se ──► Lecteur·rice (lit 2 pages) ──► Abonné·e newsletter ──► Membre (compte + OTP) ──► Membre actif·ve (1 action / semaine) ──► Pair éducateur·rice
```
Leviers par étape : contenu utile et sûr → réassurance (anonymat, gratuité) → inscription en 1 étape obligatoire → profil progressif → événements, sondages, groupes → appel à devenir pair (campagne ciblée).

## 4. Newsletter
- Fréquence : mensuelle (+ 1 numéro spécial par campagne de sensibilisation).
- Rubriques : à la une · nouvelle fiche · événement · témoignage (anonymisé, consenti) · rappel des contacts d'urgence.
- Segmentation : intérêts (Santé, Droits, Bien-être, Événements, Ressources, Sécurité numérique), tags (membre, pair, partenaire, presse, bailleur).
- Objectifs : ouverture ≥ 35 %, clic ≥ 10 %, désabonnement < 0,5 %, rebond < 3 %.

## 5. Calendrier éditorial (repères)
8 mars (droits des femmes) · 28 mai (hygiène menstruelle — Do Glegbe) · juin (mois des fiertés, contenus communautaires) · 25 novembre → 10 décembre (16 jours d'activisme contre les VBG) · 10 décembre (droits humains).
