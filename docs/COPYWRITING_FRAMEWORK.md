# Cadre de rédaction

## 1. Principe
Les méthodes de conversion classiques (urgence artificielle, peur, rareté) sont **interdites** : le public peut être en danger ou en détresse. On convainc par la **réassurance**, la **clarté** et la **preuve**.

## 2. Méthode R.A.P.A. (pages et sections)
1. **Reconnaître** la situation de la personne (« Tu as une question sur… ? Tu as vécu ou été témoin de violences ? »).
2. **Assurer** la sécurité (« anonyme », « gratuit », « confidentiel », « ta position seulement avec ton accord »).
3. **Proposer** une seule action claire (CTA de [CTA_LIBRARY.md](CTA_LIBRARY.md)).
4. **Appuyer** par une preuve (contact 24/7, nombre de fiches, expert·es identifié·es, témoignage).

## 3. Structures
| Support | Structure |
|---|---|
| Hero | Badge de réassurance → titre (promesse) → phrase (pour qui, quoi) → CTA principal + secondaire → preuve (citation, statut) |
| Section | Titre `h2` (bénéfice) → 1 à 2 phrases → 3 à 6 cartes → CTA |
| Carte | Étiquette → titre `h3` (≤ 8 mots) → description (≤ 25 mots) → lien d'action |
| Fiche thématique | Résumé (3 lignes) → avertissement de contenu si nécessaire → « Comprendre » → « Reconnaître les signes » → « Que faire ? » → « Où trouver de l'aide » |
| E-mail transactionnel | Objet explicite (≤ 50 car.) → texte d'aperçu → salutation → une information → un bouton → ce qu'il faut faire si ce n'est pas vous |
| Newsletter | Objet (bénéfice ou nouveauté, ≤ 50 car., personnalisation `{{user_first_name}}` possible) → texte d'aperçu → introduction (2 lignes) → 2 à 4 rubriques courtes avec un lien chacune → signature de l'équipe → désinscription (automatique) |
| Publication de l'équipe | Accroche (1 phrase) → information pratique (date, lieu, lien) → invitation à agir |
| Sondage | Question fermée et neutre → réponses courtes, mutuellement exclusives (≤ 80 car.) → contexte facultatif |

## 4. Lisibilité
- Niveau de langue : collège ; phrases ≤ 20 mots ; paragraphes ≤ 4 lignes sur mobile.
- Un message par phrase, voix active, verbes concrets.
- Listes à puces pour plus de deux éléments.
- Termes juridiques et médicaux expliqués à la première occurrence.

## 5. Check-list de relecture
- [ ] La personne comprend en 5 secondes de quoi il s'agit et ce qu'elle peut faire.
- [ ] La sécurité / l'anonymat est dit avant toute demande d'information.
- [ ] Une seule action principale.
- [ ] Aucun mot alarmiste ni culpabilisant.
- [ ] Tutoiement ou vouvoiement cohérent avec le contexte.
- [ ] Écriture inclusive homogène.
- [ ] Typographie française (espaces insécables, guillemets « »).
- [ ] Titre et description SEO renseignés pour les pages publiques.
